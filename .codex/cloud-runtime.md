# Codex Cloud runtime

Codex Cloud should hydrate this repository's `AGENTS.md`, repo skills, and native memory settings through `.codex/cloud-setup.sh`. Current project context and native Codex memory are authoritative for agent continuity. Use Macro for stored operational-source retrieval and originating services for current facts when those sources are reachable.

`TAILSCALE_AUTHKEY` remains optional when a Cloud task needs private-network access. Keep credentials and service tokens out of git.
